TROUBLESHOOTING IF STUCK
═══════════════════════════════════════════════════════════════════════════════

Symptom: Reward still exactly -876.37 after 10k steps
→ Action rescaling not applied
→ Check: grep "action_rescaled" plasma_control_env.py
→ Fix: Verify plasma_control_env.py has rescaling code

Symptom: Episode always 50 steps
→ Targets not being reached or penalty too strong
→ Check: tail -50 rl_training_logs/action_logging.txt | grep success
→ Fix: Verify control penalty is -0.01 and success bonus is 50.0

Symptom: Training crashes
→ Learning rate or batch size too aggressive
→ Fix: Reduce batch_size to 128 in simple_plasma_training.py
→ Rerun: python simple_plasma_training.py

Symptom: Very slow (5k steps in 30 min)
→ Normal on CPU, expected on GPU training
→ Can speedup by: Reducing eval_freq from 2000 to 5000
→ Expected: CPU ~10-15 min/50k steps, GPU ~2-3 min/50k steps
